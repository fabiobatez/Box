# Projet Box

**Box** est une application complète de messagerie connectée à Gmail.

Ce dépôt contient deux parties principales :

- **`frontend/`** : L'interface utilisateur (React + Vite).
- **`server/`** : Le serveur API et d'authentification (Express + TypeScript).

## 🚀 Démarrage Rapide

Pour lancer le projet complet, vous devez démarrer les deux parties dans des terminaux séparés.

### 1. Serveur (Backend)
```bash
cd server
npm install
npm run dev
```

### 2. Interface (Frontend)
```bash
cd frontend
npm install
npm run dev
```

Consultez le `README.md` dans chaque dossier pour plus de détails.
